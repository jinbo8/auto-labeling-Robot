## 1. 这是什么

**LeRobot** 是 Hugging Face 开源的 **真实机器人学习库**（PyTorch），把下面几件事统一到一套接口里：

| 能力 | 作用 |
|------|------|
| **数据采集** | 遥操作录制 → 标准 `LeRobotDataset`（视频/图像 + Parquet 状态动作） |
| **策略训练** | ACT / Diffusion / SmolVLA / π0 等模仿学习与 VLA |
| **仿真评测** | LIBERO、PushT、ALOHA 等 Gymnasium 环境 |
| **真机控制** | 统一 `Robot` 接口：读观测、发动作，与硬件解耦 |
| **Hub 生态** | 数据集、预训练模型可上传/下载 Hugging Face Hub |

一句话：**采集 → 训练 → 评测/部署** 的端到端工具链，降低真机机器人学习门槛。

官方仓库：https://github.com/huggingface/lerobot  
官方文档：https://huggingface.co/docs/lerobot  
数据集浏览：https://huggingface.co/lerobot

## 3. 核心概念（先建立心智模型）

```
遥操作 / 仿真
     │
     ▼
 LeRobotDataset  ←── MP4(或图像) + Parquet(state/action)
     │
     ▼
 Policy（ACT / SmolVLA / …）  ←── Processor 做归一化、裁剪等
     │
     ▼
 Robot.send_action()  或  仿真 env.step()
```

- **`LeRobotDataset`**：按 episode 组织；从 Hub 或本地加载，自动处理视频解码（依赖 **ffmpeg**）。
- **`PreTrainedPolicy`**：所有策略统一基类，支持 `from_pretrained` / 推 Hub。
- **`Robot` / `Teleoperator`**：真机与遥操作插件化；第三方包可用 `lerobot_robot_*` 前缀自动发现。
- **CLI**：日常工作几乎都用命令行，不必先写训练脚本。

## 4. 安装（与本仓库配合）

详细命令已写在 [`环境要求.txt`](./环境要求.txt)。推荐路径：

```bash
conda create -y -n lerobot python=3.12
conda activate lerobot
conda install ffmpeg -c conda-forge   # 数据集视频解码必需

cd lerobot/lerobot
pip install -e ".[training]"          # 只训练
# 或
pip install -e ".[core_scripts]"      # 录制 / 回放 / 标定
# 或
pip install -e ".[all]"               # 全量（体积大）
```

常用可选依赖示例：

```bash
pip install -e ".[feetech]"           # SO-100 / SO-101 电机
pip install -e ".[smolvla]"           # SmolVLA
pip install -e ".[diffusion]"         # Diffusion Policy
pip install -e ".[aloha,pusht]"       # 仿真环境
```

验证：

```bash
lerobot-info
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

> 本机若有 RTX 4070（约 12–16GB），训练优先选 **ACT**；有余力再试 **SmolVLA**。大 VLA（π0 等）需小 batch + 梯度累积。

## 5. 怎么用：按目标选路径

### 路径 A — 没有机械臂，先跑通训练

适合：摸清数据格式、训练流程、显存占用。

```bash
# 从 Hub 拉公开数据集训练 ACT
lerobot-train \
  --policy.type=act \
  --dataset.repo_id=lerobot/aloha_mobile_cabinet \
  --policy.device=cuda \
  --output_dir=outputs/train/act_demo \
  --batch_size=8
```

仿真评测示例：

```bash
lerobot-eval \
  --policy.path=<你的checkpoint或Hub模型> \
  --env.type=pusht \
  --eval.n_episodes=10
```

Python 读数据：

```python
from lerobot.datasets.lerobot_dataset import LeRobotDataset

ds = LeRobotDataset("lerobot/aloha_mobile_cabinet")
print(ds[0]["action"].shape)
```

可视化公开/自有数据集：https://huggingface.co/spaces/lerobot/visualize_dataset

### 路径 B — 有 SO-100 / SO-101：采集 → 训练 → 真机评估

完整流水线（端口、`id` 换成你的实际值）：

```bash
# 1) 找串口
lerobot-find-port

# 2) 电机 ID / 波特率（每台臂做一次）
lerobot-setup-motors --robot.type=so101_follower --robot.port=<FOLLOWER_PORT>
lerobot-setup-motors --teleop.type=so101_leader  --teleop.port=<LEADER_PORT>

# 3) 标定（关节扫满量程）
lerobot-calibrate --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_follower
lerobot-calibrate --teleop.type=so101_leader  --teleop.port=<LEADER_PORT>  --teleop.id=my_leader

# 4) 遥操作试跑（不录数据）
lerobot-teleoperate \
  --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_follower \
  --teleop.type=so101_leader  --teleop.port=<LEADER_PORT>  --teleop.id=my_leader \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --display_data=true

# 5) 录制数据集（→ 下一 episode，← 重录，ESC 结束）
hf auth login
HF_USER=$(hf auth whoami | head -1 | awk '{print $NF}')

lerobot-record \
  --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_follower \
  --teleop.type=so101_leader  --teleop.port=<LEADER_PORT>  --teleop.id=my_leader \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --dataset.repo_id=${HF_USER}/my_task \
  --dataset.single_task="pick the cube and place it in the box" \
  --dataset.num_episodes=50 \
  --dataset.episode_time_s=30 \
  --dataset.reset_time_s=10 \
  --display_data=true

# 6) 回放检查
lerobot-replay \
  --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_follower \
  --dataset.repo_id=${HF_USER}/my_task --dataset.episode=0

# 7) 训练
lerobot-train \
  --dataset.repo_id=${HF_USER}/my_task \
  --policy.type=act \
  --policy.device=cuda \
  --output_dir=outputs/train/act_my_task \
  --batch_size=8 \
  --policy.repo_id=${HF_USER}/act_my_task

# 8) 真机用策略推理（用 record + policy.path）
lerobot-record \
  --robot.type=so101_follower --robot.port=<FOLLOWER_PORT> --robot.id=my_follower \
  --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}}" \
  --dataset.repo_id=${HF_USER}/eval_my_task \
  --dataset.single_task="pick the cube and place it in the box" \
  --dataset.num_episodes=10 \
  --policy.path=${HF_USER}/act_my_task
```

更细的 SO 机型说明见源码文档：`lerobot/docs/source/so101.mdx`、`il_robots.mdx`。

## 7. 策略怎么选（实用建议）

| 策略 | 显存大致需求 | 适合场景 |
|------|----------------|----------|
| **ACT** | ~1–4 GB 级（很友好） | **首选入门**、单任务、笔记本/消费级 GPU |
| **Diffusion** | 中等 | 动作多峰分布 |
| **SmolVLA** | 中等 | 多任务、语言条件；可解冻视觉编码器提效果 |
| **π0 / π0.5 / XVLA 等** | 约 16GB+ | 大模型 VLA；小显存需极小 batch |

训练时长经验：模仿学习常 **5–10 个 epoch** 即可看效果；数据差时优先 **加数据/提高演示质量**，而不是盲目加步数。

采集建议（官方经验）：

- 先 **50 条** 高质量 episode，固定相机与物体位姿，训通 ACT  
- 再沿一个维度加多样性（位置 → 光照 → 物体）  
- 相机：能只看画面就完成任务；推荐固定机位 + 腕部相机

## 9. 常见问题

**Q: 装了但导入到 CPU 版 torch？**  
检查是否被 `~/.local/lib/python3.x/site-packages` 的 CPU 包覆盖；可用 `PYTHONNOUSERSITE=1` 验证，并卸载用户目录下的 `torch`。

**Q: 数据集视频读不了？**  
确认 `ffmpeg` 已装（conda-forge），且 `lerobot[dataset]` / `torchcodec` 或 `av` 正常。

**Q: SO 臂通信超时？**  
先查电机红灯与供电电压（5V/7.4V 与 12V 机型不可混用），再查串口权限（Linux：`/dev/ttyACM*`）。

**Q: Hub 下载慢？**  
配置 Hugging Face 镜像或代理；训练时也可先把数据集缓存到本地再指定路径。

## 11. 建议你的下一步（可直接照做）

1. 按 `环境要求.txt` 建好 `lerobot` conda 环境并装上 ffmpeg。  
2. `cd lerobot/lerobot && pip install -e ".[training]"`，跑通 `lerobot-info`。  
3. 用公开数据集跑一次 `lerobot-train --policy.type=act ...`，确认 GPU 正常。  
4. 有硬件再走路径 B；没有则继续读 `examples/tutorial/act` 与 Hub 上的数据集。  
5. 需要对接本仓库标注管线时，再深入 `datasets/` 与 `examples/port_datasets/`。
