# 04 — Annotator Studio 交互规范

目标：在 **Web** 上复现 X-AnyLabeling 的高效自动标注心智，并加上机器人多相机 / episode 时间轴。  
参考实现：`github/X-AnyLabeling`（交互与面板信息架构）；**不**嵌入 PyQt。

## 1. 信息架构（三栏 + 底轴）

```text
┌────────────┬──────────────────────────────┬────────────┐
│ 资源导航    │         主画布                │ 右侧面板   │
│ Episode    │  当前相机帧 / 叠加标注         │ 标签本体   │
│ 相机列表    │  SAM 提示点/框               │ 模型与预标 │
│ Job 状态   │                              │ 属性/实例  │
├────────────┴──────────────────────────────┴────────────┤
│ 时间轴：帧 scrub · 多相机缩略条 · 轨迹只读条（action）   │
└────────────────────────────────────────────────────────┘
```

### 1.1 左侧 — 资源导航

- 当前 Job 的 `episode_index`、task 文本只读展示。  
- 相机切换：`top` / `wrist` 等；切换保持同一 `frame_index`。  
- 作业状态徽章：`annotating` / `submitted` 等。  
- 快捷：上一/下一未完成帧、仅显示有 Issue 的帧（审核模式）。  

### 1.2 中间 — 主画布

- 缩放平移（滚轮 / 空格+拖拽，对标常见标注工具）。  
- 工具：选择、矩形、多边形、笔刷掩码（MVP 可后置笔刷）、SAM 点、SAM 框。  
- 叠加层开关：Annotation / Prediction（半透明区分色）/ 网格。  
- 预览使用 **H.264 预览轨**；原片 AV1 不直接喂给不支持的浏览器控件。  

### 1.3 右侧 — 标签与模型

- 本体标签列表（颜色、热键）。  
- 模型面板：  
  - SAM2：点正/负样本、框提示、清除提示、解码一次  
  - SAM3：文本框（可默认填标签的 `prompt_text`）、置信度阈值  
  - 「应用到当前帧」 / 「传播到 episode 内 N 帧」（调 Track Worker 或同步短片段）  
- 实例列表：`track_id`、标签、来源、分数；支持删除、改类、接受预标。  

### 1.4 底栏 — 时间轴

- 帧滑块 + 输入跳转。  
- 多相机迷你条对齐同一时间。  
- 只读 **action / state** 曲线或关键关节迷你图（数据来自 RobotDataset，不要求可编辑）。  
- 标注密度热力：有标注的帧打点，方便跳修。  

## 2. 核心交互流（对标 XAL）

### 2.1 点选 SAM2

1. 选标签（如 `cube`）。  
2. 工具切到 SAM 点；左键正点、右键或 Alt+点击负点。  
3. 自动或按 `Enter` 请求 `/models/sam2/predict`。  
4. 预览 mask → `Accept` 写入 Annotation（source=`sam2`）或落入 Prediction 再接受。  

### 2.2 框选 SAM2

1. 拖框作为提示。  
2. 解码 mask / 精细化为 polygon（项目设置：保留 mask 或转 polygon）。  

### 2.3 SAM3 文本

1. 输入或选用标签别名文本（如 `red cube`）。  
2. 当前帧出多实例；列表多选 Accept。  
3. 批量预标由 Manager 在 Portal 触发，Studio 内以 Prediction 层展示。  

### 2.4 视频传播

1. 在关键帧确认实例。  
2. 「向后传播」/「双向」→ Track Worker（SAM2/SAM3 video API）。  
3. 传播结果为 Prediction；人工 scrub 修正后 Accept。  

### 2.5 接受 / 拒绝预标

- 单实例 Accept / 当前帧全部 Accept / 按分数阈值 Accept。  
- Reject 删除 Prediction 或标记忽略，不进入导出。  

## 3. 快捷键（建议默认，可配置）

| 键 | 动作 |
| --- | --- |
| `V` | 选择工具 |
| `R` | 矩形 |
| `P` | 多边形 |
| `S` | SAM 点 |
| `B` | SAM 框 |
| `1`–`9` | 标签热键 |
| `A` / `D` 或 `←`/`→` | 上一帧 / 下一帧 |
| `W` / `Q` | 切换相机 |
| `Enter` | 确认当前 SAM 结果 |
| `Ctrl+Enter` | 提交 Job |
| `Del` | 删除选中 |
| `Space` | 播放/暂停预览（短片段） |

交互文案与按钮层级保持「少弹窗、多画布内确认」，贴近 X-AnyLabeling 桌面效率。

## 4. Portal（管理端）与 Studio 分工

| 能力 | Portal | Studio |
| --- | --- | --- |
| 导入数据集、QA 报告 | ✓ | 只读入口链接 |
| 本体编辑、预标策略 | ✓ | 只读当前版本 |
| 拆 Job、分派 | ✓ | — |
| 标注与交互 SAM | — | ✓ |
| 审核 Issue | 列表 | 帧内定位 |
| 导出 | ✓ | — |

## 5. 审核模式差异

- 只读几何，可添加 Issue 图钉（帧 + 相机 + 类型：漏标/错类/不齐）。  
- 对比视图（可选 Team）：Annotation vs Prediction。  

## 6. 性能与体验约束

- 首屏：当前帧图 + 相邻 ±2 帧预取。  
- SAM 交互目标：GPU 空闲时单次预测 < 300ms 量级（1080p 可降采样推理再映射回原图）。  
- 长 episode：时间轴虚拟滚动；标注按帧窗口懒加载。  
- 明确提示：原视频为 AV1 时「预览已转码，下载原片另开」。  

## 7. 无障碍与国际化（Team+）

- 界面中英切换；快捷键避免与浏览器冲突。  
- 色盲友好：标签不只靠颜色，实例列表带文字。
