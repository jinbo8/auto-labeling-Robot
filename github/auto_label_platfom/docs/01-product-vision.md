# 01 — 产品愿景与商业定位

## 1. 问题陈述

具身智能 / VLA 团队的日常数据流是：

1. 遥操作或仿真录制多相机 episode（状态、动作、语言任务、视频）  
2. 人工或半自动补视觉语义（物体框、掩码、关键帧、失败段）  
3. 质检后导出给模仿学习 / VLA 训练  

现有开源工具各擅胜场，但**没有一条原生闭环**：

| 工具 | 强项 | 对机器人数据的缺口 |
| --- | --- | --- |
| X-AnyLabeling | 单机 AI 预标体验好 | 无多租户协作；不理解 LeRobot episode / 多相机同步 |
| CVAT | 团队作业、视频、审核 | 机器人轨迹与 task 为二等公民；SAM2/3 在社区版能力有限 |
| Label Studio | 本体灵活、ML Backend | CV 视频深度与机器人格式弱 |

本平台要成为：**以机器人数据集为一级公民的 Web 自动标注与协作平台**。

## 2. 产品一句话

面向具身智能数据团队的 **「采集 → 质检 → 自动预标 → 人机协同修订 → 审核导出 → 训练回流」** Web 平台。

## 3. 目标用户

| 角色 | 诉求 |
| --- | --- |
| 数据负责人 / Manager | 导入数据集、看 QA、配本体与预标策略、拆任务、控进度与导出 |
| 标注员 Annotator | 在 Studio 里快速改 SAM 预标、多相机对齐 scrub、少键盘切换 |
| 质检 Reviewer | 抽检、驳回带 Issue、看一致率 |
| 算法工程师 | 拿稳定导出（COCO / YOLO / LeRobot 扩展）、触发回流训练 |
| 平台管理员 | 租户、GPU 配额、模型版本、私有化部署 |

## 4. 核心场景（V1）

1. **导入 LeRobot v3**：识别 `meta/info.json`、episodes、分相机 mp4、tasks。  
2. **数据质检**：对齐 / fps / 模糊 / 过曝 / 卡帧；报告挂到项目（复用本仓 `lerobot/script` 思路）。  
3. **概念预标**：SAM3 文本（如 `cube`、`box`、`gripper`）对关键帧或抽帧批量出掩码/框。  
4. **视频传播**：SAM2/SAM3 在 episode 内传播实例，人工只修关键帧。  
5. **作业分发与审核**：按 episode 拆 Job；通过后导出训练包。  

样例数据集：`lerobot/datasets/svla_so100_pickplace`（SO-100 抓放，双相机 top + wrist）。

## 5. 竞品能力取舍（少而精）

| 来源 | 吸收 | V1 刻意不做 |
| --- | --- | --- |
| X-AnyLabeling | 画布交互、点/框 SAM、模型切换与批量预标心智、导出习惯 | PyQt 桌面壳、巨型本地 model zoo 全量搬迁 |
| CVAT | Project / Task / Job、角色分发、Review / Issue、视频时间轴作业 | 3D 点云全套、Nuclio 全家桶原样照搬 |
| Label Studio | 标签本体可配置、ML Backend 预测协议、项目模板 | 音频 / NLP 全模态首发 |
| SAM2 / SAM3 | 图像/视频分割与传播；文本概念预标 | 自研基础分割大模型 |

## 6. 差异化卖点

1. **LeRobot-native**：episode 为作业原子；多相机同步；action / state / task 只读叠加。  
2. **预览友好**：原片可保留 AV1；浏览器预览轨统一转 H.264（规避「需要 AV1 解码器」）。  
3. **质检内建**：标注前先挡脏数据，降低无效人工。  
4. **模型可插拔**：SAM2/3 主链路；YOLO / VLM 通过同一 Prediction 协议扩展。  

## 7. 商业化能力包

| 包 | 内容 | 典型买家 |
| --- | --- | --- |
| Community / 内部版 | 单机 Compose、SAM 交互、LeRobot 导入导出 | 实验室、创业早期 |
| Team | 角色、分发、审核、批量预标队列、质检报表 | 具身数据团队 5–50 人 |
| Enterprise | 多租户、OIDC、私有模型仓、SLA、定制本体与训练回流 | 车企 / 机器人公司私有化 |

计费可组合：席位 + GPU 预标时长 + 存储；Enterprise 年费 + 驻场。

## 8. 成功指标（产品）

- 单 episode 有效标注人时相对「纯手动画框」下降 ≥ 50%（有预标 + 传播时）  
- 导入到可训练导出的端到端路径文档化，新人 < 1 天跑通样例集  
- Team 版：任务完成率、驳回率、预标采纳率可看板  

## 9. 非目标（明确写出以免范围膨胀）

- 不做通用「第二个 Label Studio」全模态平台  
- V1 不做桌面客户端、不做联邦学习、不做自研大模型训练平台（可对接外部训练）  
- 不绑定单一云厂商；对象存储 API 兼容 S3 即可
